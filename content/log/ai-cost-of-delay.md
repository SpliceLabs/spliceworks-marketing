Every month AI isn't running a workflow it could take on, you don't get the value that workflow would bring. Put an average monthly value on each workflow, multiply by how many there are, then by the months you wait. That's your cost of delay: value you don't get, counted before you spend anything on implementation.

## How the number is built

An AI opportunity is one workflow AI could take on, such as answering support tickets or preparing invoices. Count each one once, so the same hours or revenue aren't counted twice.

- **Lost each month you wait** = AI opportunities × value of each workflow
- **Total if you wait** = lost each month × months you wait
- **If value builds up slowly** = half the total. That's our assumption for a workflow that takes time to reach full value, not a measured figure.
