# Editorial site — UI kit

Inferred surface. The only product hint in the sources was the zip name "Editorial habitat hero design", so this kit shows an editorial publication site (a journal about habitats) built from the Splice Works foundations and components. **No real product screens were supplied** — treat layouts as a proposal, not a recreation.

Screens (click-through in index.html): Home (hero + latest issue grid), Article (prose page), Subscribe (form + dialog + toast).

Files: Nav.jsx, Hero.jsx, ArticleGrid.jsx, Article.jsx, Subscribe.jsx, Footer.jsx, app.jsx. All UI primitives come from the compiled bundle (window.SpliceWorksDesignSystem_f2e5fb).
